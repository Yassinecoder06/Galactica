# 🚀 Galactica

A 2D arcade space shooter built with **Python** and **Pygame**, supporting both single-player survival and local two-player multiplayer modes.

---

## 🎮 Gameplay

- Dodge incoming projectiles whose speed dynamically increases over time.
- Shoot down projectiles with your spacecraft's laser cannon to clear your path and survive.
- Compete or team up with a friend in **local multiplayer**.

---

## ⌨️ Controls

| Key | Action |
| :--- | :--- |
| `S` | Start **Single-Player** mode |
| `M` | Start **Multiplayer** mode |
| `Arrow Keys` | Move Player 1 spacecraft |
| `Right Ctrl` | Shoot (Player 1) |
| `E` / `D` / `S` / `X` | Move Player 2 spacecraft |
| `Space` | Shoot (Player 2) |
| `F` | Toggle Fullscreen |
| `P` / `C` | Pause / Continue game |
| `Q` | Quit game |

---

## ⚙️ Setup & Run

1. Install **Pygame**:
   ```bash
   pip install pygame
   ```
2. Launch the game:
   ```bash
   python main.py
   ```
3. Customize screen and game settings in `screen/configuration` if needed.
